JeevSetu AI — Section 12: Substance Use History
Standalone browser prototype. Open index.html in Chrome (works offline).

Changes from the uploaded Section 8 prototype:
- Renamed throughout to Section 12; Section 8 is reserved for Occupational History.
- Additional-information Yes opens a text box; No records no additional information.
- Neither answer automatically navigates to the clinical note.
- Generate Clinical Note is enabled only after selecting substances or None and completing the additional-information question.
- Clinical note displays a table of substance, status, frequency, and duration, followed by additional information.
- Entered substance details are retained when changing selections.
- Current-use clinician attention prompt is screening only, not a diagnosis.

This prototype runs locally in the browser. No data is uploaded or persisted.
