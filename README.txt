Medication & Therapeutic-Product History

Updated version:
- Allopathic medicines: complete medicine-by-medicine capture.
- Ayurvedic medicines: complete medicine/product-by-product capture in the same structure.
- Herbal medicines/products: complete capture in the same structure.
- Vitamins: complete capture in the same structure.
- Minerals: complete capture in the same structure.
- Dietary/nutritional supplements: complete capture in the same structure.
- For each category: product name, composition/ingredients, strength, prescribed amount, actual amount, frequency, duration, food relation, difference/reason, and adverse effects.
- Medication discontinuation with explicit reason.
- Explicit capture of stopping without doctor consultation.
- Explicit capture of self-restarting an old medicine when the same problem recurs.
- OTC medicines and antibiotics.
- Clinical Note preview includes these products so the clinician receives the complete medication/product list.

This is a field-trial prototype, not a production EMR.
