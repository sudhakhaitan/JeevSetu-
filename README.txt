JeevSetu V2-5-125 — Patient ID Entry Screen (First Step)

Adds an entry screen with Fresh Form, Update Existing Record lookup, and View Clinical Note lookup. Existing history-taking sections and navigation are retained underneath the entry screen.
The generated Patient ID is saved with the current local patient profile for lookup. Existing-record lookup is limited to the current browser record; full multi-patient archive and complete form restoration are not claimed by this build.

Privacy: local browser storage only; no server upload. Use dummy data first and verify the full workflow before clinical use. Save a JSON backup before starting a new record if an earlier record may be present.
