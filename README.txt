JeevSetu V2-5-124 — Privacy Edition (Hindi) — JSON Restore Update
====================================================================

इस ZIP में स्थानीय रिकॉर्ड के बैकअप डाउनलोड करने के साथ-साथ JSON बैकअप से रिकॉर्ड वापस लाने का विकल्प भी है।

रिकॉर्ड को फिर से खोलने का तरीका:
1. मरीज का रिकॉर्ड भरते समय समय-समय पर “मौजूदा मरीज के रिकॉर्ड का बैकअप डाउनलोड करें (JSON)” दबाएँ।
2. डाउनलोड हुई JSON फ़ाइल को सुरक्षित रखें। इसमें संवेदनशील स्वास्थ्य जानकारी हो सकती है।
3. बाद में रिकॉर्ड खाली दिखे, तो JeevSetu पेज खोलें।
4. “JSON बैकअप से रिकॉर्ड वापस लाएँ” वाले भाग में उसी मरीज की JSON फ़ाइल चुनें।
5. “JSON बैकअप से रिकॉर्ड वापस लाएँ” दबाएँ और पुष्टि होने पर पेज Reload करें।
6. आगे काम करने के बाद फिर नया बैकअप डाउनलोड करें।

महत्वपूर्ण:
- JSON बैकअप एक डेटा फ़ाइल है; इसे Chrome में सामान्य वेबपेज की तरह खोलने से मरीज का फॉर्म दोबारा नहीं खुलेगा। इसे JeevSetu के अंदर दिए गए Restore विकल्प से आयात करें।
- ऐप डेटा को सर्वर पर अपलोड नहीं करता। डेटा इसी डिवाइस/ब्राउज़र के localStorage में रहता है; यह एन्क्रिप्टेड नहीं है।
- अलग ब्राउज़र, अलग फ़ाइल-लोकेशन, ब्राउज़र का डेटा साफ़ करना या स्टोरेज हटना रिकॉर्ड की उपलब्धता को प्रभावित कर सकता है। JSON बैकअप अलग से सुरक्षित रखें।
- यह प्रोटोटाइप है; वास्तविक क्लिनिकल उपयोग से पहले डिवाइस और डेटा-रिकवरी परीक्षण आवश्यक हैं।
