JeevSetu Section 6 — Standalone Field Trial
Medication & Therapeutic-Product History

Open index.html in Chrome. No internet connection is required for this standalone prototype.

Includes:
- Current medication capture
- Medicine-by-medicine prescribed vs actual use
- Strength, dose, frequency, duration and food relation
- Medication discontinuation with explicit reason
- Explicit capture of stopping a medicine without doctor consultation
- Explicit capture of self-restarting an old medicine when the same problem recurs
- OTC, antibiotics, Ayurvedic/herbal products, vitamins/minerals/supplements
- Other-product capture
- Clinical-note preview
- Local device save and JSON export

This is a field-trial prototype, not a production EMR.
