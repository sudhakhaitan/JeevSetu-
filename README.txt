JeevSetu Section 4 — Standalone Test Build

This build contains ONLY Section 4: Family History.
It is intentionally independent of Sections 1–3.

Workflow:
A. Parents: alive/deceased/unknown; cause of death if deceased.
B. Siblings: number of brothers/sisters; deceased siblings and cause of death.
C. Disease-first family history: select multiple diseases, then multiple blood relatives for each disease.
D. Consanguinity: parents' marriage and patient's own marriage.

Open index.html in Chrome.
Data is stored locally in the browser and can be exported as JSON.
