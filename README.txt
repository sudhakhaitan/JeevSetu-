JeevSetu V2-5-124 — Privacy Edition (Hindi) — Restore Diagnostic Update
=======================================================================

इस ZIP में स्थानीय रिकॉर्ड का JSON बैकअप डाउनलोड करने और JSON से रिकॉर्ड वापस लाने का विकल्प है। Restore के समय ऐप अब डेटा फ़ील्ड की संख्या दिखाता है, स्टोरेज में लिखे डेटा को सत्यापित करता है और यदि बैकअप के नोट्स में कई Patient ID मिलती हैं तो पहले चेतावनी देता है।

रिकॉर्ड वापस लाने का तरीका:
1. JeevSetu को उसी GitHub Pages पते और उसी Chrome प्रोफ़ाइल में खोलें जहाँ पहले रिकॉर्ड भरा था।
2. ऊपर “JSON बैकअप से रिकॉर्ड वापस लाएँ” भाग में JSON फ़ाइल चुनें।
3. “JSON बैकअप से रिकॉर्ड वापस लाएँ” दबाएँ।
4. यदि कई Patient ID की चेतावनी आए, तो रिकॉर्ड आयात करने से पहले पुष्टि करें। अलग-अलग मरीजों के नोट आपस में मिले हो सकते हैं।
5. पुष्टि के बाद Reload करें। फिर सही मरीज/सेक्शन खोलकर रिकॉर्ड जाँचें।
6. सफल सुधार के बाद नया JSON बैकअप डाउनलोड करें और उसे सुरक्षित रखें।

महत्वपूर्ण सीमाएँ:
- JSON फ़ाइल को Chrome में सीधे खोलने से वह ऐप में Restore नहीं होती; उसे JeevSetu पेज के Restore विकल्प से आयात करें।
- JSON बैकअप एक ब्राउज़र स्टोरेज snapshot है, मरीजों की अलग-अलग सूची नहीं। इसमें पुराने/अलग मरीजों के नोट बचे हों तो ऐप उन्हें अपने-आप सही मरीज में नहीं बाँट सकता।
- ऐप डेटा को सर्वर पर अपलोड नहीं करता। डेटा इसी डिवाइस/ब्राउज़र के localStorage में रहता है; यह एन्क्रिप्टेड नहीं है।
- रिकॉर्ड केवल उसी origin (उदाहरण: वही GitHub Pages URL), ब्राउज़र और प्रोफ़ाइल में उपलब्ध होगा। अलग file:// पेज, दूसरा ब्राउज़र/प्रोफ़ाइल या साफ़ किया गया browser data अलग स्टोरेज दिखा सकता है।
- यह प्रोटोटाइप है; वास्तविक क्लिनिकल उपयोग से पहले क्लिनिकल और डिवाइस परीक्षण आवश्यक हैं।


Restore fix: आयात से पहले पुराने JeevSetu app keys का snapshot लिया जाता है, stale app keys हटाकर बैकअप लिखा/सत्यापित किया जाता है; विफलता पर पुराने keys वापस रखने की कोशिश होती है।
