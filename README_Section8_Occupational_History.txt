HOW TO TEST
1. Extract the ZIP file.
2. Open the HTML file in Google Chrome.
3. Complete Section 8 one question at a time.
4. Test both Yes and No branches wherever conditional questions are present.
5. Confirm that the final Clinical Note is generated only after Section 8 is completed.

IMPORTANT LOGIC
• Ask only one question at a time.
• Use simple Hindi suitable for a rural patient.
• Conditional questions should appear only when relevant.
• If the patient answers Yes to an exposure or symptom question, capture the related details.
• Additional information should be recorded as provided, without adding interpretation.
• If the patient identifies an error at final confirmation, allow correction before completing the section.
• The clinician-facing output should be concise and preferably table-based.
